# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within **RideShare Pro**, please do not open a public issue. Instead, please report it privately:

1. Send an email to `vivekchavan3552@gmail.com` with the subject:
   `[SECURITY] Vulnerability Report: RideShare Pro`
2. Include:
   - Type of vulnerability (e.g. SQL injection, authentication bypass, CSRF)
   - Step-by-step instructions to reproduce the issue
   - Proof-of-concept exploit code or HTTP requests if available
   - Suggested fix or mitigation (optional)

We will acknowledge receipt of your report within 48 hours and work with you to resolve the issue before disclosing it publicly.
